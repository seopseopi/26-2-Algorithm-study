# 2주차 공통 문제

- 활동일: 2026-10-12
- 문제: [2110. 공유기 설치](https://www.acmicpc.net/problem/2110)
- solved.ac 난이도: Gold IV ([solved.ac 문제 목록](https://solved.ac/en/problems/level/12?page=2)에서 확인)
- 학습 주제: 정렬, 이분 탐색

## 학습 목표

입력 크기를 보고 효율적인 탐색 방법을 선택하고, 정렬된 자료에서 조건을 만족하는 답을 찾는 과정을 연습합니다.

## 문제 요약

여러 집의 좌표와 설치할 공유기 수가 주어집니다. 공유기를 집에 설치해 가장 가까운 공유기 사이의 거리를 최대화하고, 그 최대 거리를 출력합니다.

## 입력 및 출력

- 집의 수 `N`은 2 이상 200,000 이하이고, 공유기 수 `C`는 2 이상 `N` 이하입니다.
- 각 집의 좌표는 0 이상 1,000,000,000 이하입니다.
- 출력은 가장 인접한 두 공유기 사이 거리의 가능한 최댓값입니다.
- 문제의 시간 제한은 1초, 메모리 제한은 128MB입니다.

## 과목 수준에 적합한 이유

집 좌표를 정렬한 뒤 입력 크기에 맞는 알고리즘을 설계해야 합니다. 기본 정렬과 이분 탐색을 조합해 최적화 문제를 다루므로 대학 알고리즘 과목에서 배우는 핵심 기법의 응용을 연습하기 좋습니다.
