# 2주차 공통 문제

- 활동일: 2026-10-12
- 문제: 2110. 공유기 설치
- 백준의 이전 공식 주소: https://www.acmicpc.net/problem/2110 (서비스 종료로 현재 접속 불가)
- solved.ac 난이도: Gold IV ([solved.ac 문제 목록](https://solved.ac/en/problems/level/12?page=2)에서 확인)
- 학습 주제: 정렬, 이분 탐색

## 학습 목표

입력 크기를 보고 효율적인 탐색 방법을 선택하고, 정렬된 자료에서 조건을 만족하는 답을 찾는 과정을 연습합니다.

## 문제

수직선 위에 `N`채의 집이 있고, 각 집은 서로 다른 정수 좌표에 있습니다. 집이 있는 위치에 공유기를 설치할 수 있으며, 한 집에는 공유기를 하나만 설치할 수 있습니다. 이 중 `C`채를 골라 공유기를 설치할 때, 공유기 사이 거리 중 가장 짧은 거리가 최대가 되도록 배치해야 합니다. 그때의 가장 짧은 거리를 출력하세요.

## 입력

첫째 줄에 집의 수 `N`과 설치할 공유기의 수 `C`가 공백으로 구분되어 주어집니다. 다음 `N`개 줄에는 각 집의 좌표 `x_i`가 한 줄에 하나씩 주어집니다.

## 출력

공유기 사이의 최소 거리가 될 수 있는 값 중 최댓값을 한 줄에 출력합니다.

## 제한

- `2 ≤ N ≤ 200,000`
- `2 ≤ C ≤ N`
- `0 ≤ x_i ≤ 1,000,000,000`
- 모든 집의 좌표는 서로 다릅니다.
- 시간 제한: 2초
- 메모리 제한: 128MB

## 예제

입력:

```text
5 3
1
2
8
4
9
```

출력:

```text
3
```

## 과목 수준에 적합한 이유

집 좌표를 정렬한 뒤 입력 크기에 맞는 알고리즘을 설계해야 합니다. 기본 정렬과 이분 탐색을 조합해 최적화 문제를 다루므로 대학 알고리즘 과목에서 배우는 핵심 기법의 응용을 연습하기 좋습니다.
