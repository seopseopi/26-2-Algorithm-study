# 2주차 공통 문제

- 활동일: 2026-10-12
- 문제: 2110. 공유기 설치
- 백준의 이전 공식 주소: https://www.acmicpc.net/problem/2110 (서비스 종료로 현재 접속 불가)
- solved.ac 난이도: Gold IV ([solved.ac 문제 목록](https://solved.ac/en/problems/level/12?page=2)에서 확인)
- 학습 주제: 정렬, 이분 탐색

## 학습 목표

입력 크기를 보고 효율적인 탐색 방법을 선택하고, 정렬된 자료에서 조건을 만족하는 답을 찾는 과정을 연습합니다.

## 문제 요약

수직선 위에 서로 다른 좌표에 있는 집 `N`채가 있습니다. 공유기는 집이 있는 위치에만 설치할 수 있고, 이 중 `C`채에 설치합니다. 설치한 공유기 사이의 거리 중 가장 짧은 값이 최대가 되도록 배치하고, 그 최대값을 출력합니다.

## 입력 및 출력

- 첫째 줄에 집의 수 `N`과 공유기 수 `C`가 주어집니다 (`2 ≤ N ≤ 200,000`, `2 ≤ C ≤ N`).
- 다음 `N`개 줄에는 서로 다른 집 좌표가 하나씩 주어집니다. 좌표는 0 이상 1,000,000,000 이하입니다.
- 한 줄에 가장 인접한 두 공유기 사이 거리의 최댓값을 출력합니다.
- 문제의 시간 제한은 1초, 메모리 제한은 128MB입니다.

## 과목 수준에 적합한 이유

집 좌표를 정렬한 뒤 입력 크기에 맞는 알고리즘을 설계해야 합니다. 기본 정렬과 이분 탐색을 조합해 최적화 문제를 다루므로 대학 알고리즘 과목에서 배우는 핵심 기법의 응용을 연습하기 좋습니다.
