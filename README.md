# 탐욕적 알고리즘

매주 백준 문제를 정확히 1개 선정해 함께 풉니다.

## 저장 규칙

- `main`에는 공통 문제와 스터디 안내를 저장합니다.
- 개인 정답 코드와 해설은 각자의 개인 브랜치에 저장합니다.
- 개인 풀이를 `main`에 병합하거나 풀이 병합용 PR을 만들지 않습니다.
- 개인 풀이는 `solutions/<github-id>/weekNN/` 아래에 두고, 코드와 함께 `README.md`에 분석과 풀이를 정리합니다.

## 주차별 문제

| 주차 | 활동일 | 문제 | 난이도 | 학습 주제 |
| --- | --- | --- | --- | --- |
| 2주차 | 2026-10-12 | [2110. 공유기 설치](problems/week02/README.md) | Gold IV | 정렬, 이분 탐색 |

## 개인 브랜치에서 문제 가져오기

개인 브랜치에서 `main`의 공통 문제 문서를 가져옵니다.

```bash
git switch <개인-브랜치>
git fetch origin
git merge origin/main
```

문제를 푼 뒤 `solutions/<github-id>/weekNN/`에 코드와 해설을 추가하고 개인 브랜치에 커밋합니다.
