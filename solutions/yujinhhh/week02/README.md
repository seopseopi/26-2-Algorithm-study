# 2110. 공유기 설치

- 난이도: Gold IV
- 알고리즘: 정렬, 그리디, 이분 탐색(매개변수 탐색)
- 언어: C++17
- 코드: [2110.cpp](2110.cpp)

## 문제 분석

N개의 집 중 C개를 골라 공유기를 설치할 때, 공유기 사이 최소 거리를 최대화한다. N이 최대 200,000이므로 모든 배치를 확인하는 방법은 사용할 수 없다.

최소 거리를 d 이상으로 유지하면서 공유기를 C개 설치할 수 있는지 판단한다. d에서 설치할 수 있다면 더 작은 거리에서도 가능하고, d에서 불가능하다면 더 큰 거리에서도 불가능하다. 따라서 가능한 거리의 최댓값을 이분 탐색한다.

## 설치 가능 여부 판단

집 좌표를 오름차순으로 정렬한다. 가장 왼쪽 집에 첫 공유기를 설치한 뒤, 마지막 설치 위치에서 d 이상 떨어진 첫 집에 다음 공유기를 설치한다. 이렇게 설치한 수가 C 이상이면 거리 d는 가능하다. C개보다 많이 설치했다면 일부를 제거해도 최소 거리는 줄어들지 않는다.

## 그리디가 올바른 이유

거리 d를 지키는 임의의 배치와 비교하면, 그리디의 첫 공유기는 그 배치의 첫 공유기보다 오른쪽에 있지 않다. 그리디의 k번째 공유기가 임의 배치의 k번째 공유기보다 오른쪽에 있지 않다고 가정하자. 임의 배치의 k+1번째 집은 그리디의 k번째 위치에서도 d 이상 떨어져 있으므로 다음 설치 후보가 된다. 그리디는 가능한 첫 집을 선택하므로 k+1번째 위치 역시 더 오른쪽에 있지 않다.

따라서 C개를 설치하는 배치가 있다면 그리디도 C개 이상 설치할 수 있다. 반대로 그리디가 C개를 설치했다면 그 자체가 가능한 배치이므로 판정은 정확하다.

## 이분 탐색

1. 좌표를 정렬하고 탐색 범위를 1부터 가장 오른쪽 집과 왼쪽 집의 거리까지로 설정한다.
2. 중간 거리에서 그리디로 공유기를 설치한다.
3. C개 이상 설치했다면 정답 후보를 저장하고 더 큰 거리를 탐색한다.
4. C개 미만이면 더 작은 거리를 탐색한다.
5. 탐색이 끝나면 저장한 최댓값을 출력한다.

집 좌표는 서로 다른 정수이고 C ≤ N이므로 최소 거리 1은 항상 가능하다. 가능 판정에서는 그 이하를, 불가능 판정에서는 그 이상을 탐색에서 제외하므로 마지막 정답 후보가 가능한 최대 거리다.

## 예제

정렬한 좌표는 [1, 2, 4, 8, 9]이다. 최소 거리 3에서는 1, 4, 8에 공유기 3개를 설치할 수 있다. 최소 거리 4에서는 그리디로 1, 8에 2개만 설치할 수 있으므로 정답은 3이다.

## 복잡도

D를 가장 오른쪽 집과 왼쪽 집의 거리라고 하면 정렬에 O(N log N), 각 거리 판정에 O(N), 이분 탐색에 O(log D)가 필요하다.

- 시간: O(N log N + N log D)
- 공간: O(N). 집 좌표를 저장하는 벡터가 필요하고, 설치 가능 여부는 추가 배열 없이 판정한다.

## 검증

- 제공 예제: 정답 3
- 집 2개, 좌표 0과 1,000,000,000: 정답 1,000,000,000
- 모든 집에 설치하는 경우: 정렬 후 인접한 집 사이 최소 간격과 일치
- 작은 무작위 입력 1,000건: 모든 C개 조합을 비교하는 완전탐색과 결과 일치
- N = C = 200,000, 좌표 간격 5,000: 정답 5,000
