# 2주차 · BOJ 2110 공유기 설치 (Gold IV)

- 언어: C++17
- 코드: [BOJ_2110.cpp](BOJ_2110.cpp)
- 핵심 기법: 정렬, 매개변수 탐색(이분 탐색), 그리디 판정

## 문제 분석

`N`채의 집 중 `C`채에 공유기를 설치할 때, **인접한 공유기 사이 거리의 최솟값을 최대화**해야 합니다.

- `N ≤ 200,000`이라 `C`채를 고르는 모든 조합을 보는 방법은 불가능합니다.
- 좌표가 최대 `1,000,000,000`이라 거리 후보를 하나씩 다 시도하는 것도 너무 느립니다.

"최솟값의 최댓값"을 구하는 문제는 질문을 뒤집으면 쉬워집니다.

> 최소 거리를 `d` 이상으로 유지하면서 공유기를 `C`개 설치할 수 있는가?

이 질문은 `d`가 작을수록 쉽고, 클수록 어렵습니다. 어떤 `d`에서 가능하면 그보다 작은 거리에서도 항상 가능하고, 불가능하면 더 큰 거리에서도 불가능합니다. 이렇게 답이 `가능 … 가능 | 불가능 … 불가능`으로 한 번만 바뀌므로, 경계를 **이분 탐색**으로 찾을 수 있습니다.

## 풀이

### 1. 정렬

집 좌표를 오름차순으로 정렬합니다. 그래야 왼쪽부터 차례로 보면서 "직전에 설치한 집과의 거리"를 계산할 수 있습니다.

### 2. 판정 함수 `canInstall(d)` — 그리디

1. 가장 왼쪽 집에 공유기를 설치합니다.
2. 오른쪽으로 가면서, 직전에 설치한 집과의 거리가 `d` 이상인 첫 집에 설치합니다.
3. 설치한 개수가 `C` 이상이면 `true`입니다.

가능한 한 **왼쪽에 일찍 설치**하는 것이 남은 집에 더 많은 공유기를 둘 여지를 남기므로, 이 그리디가 최대 설치 개수를 구합니다. 한 번 판정에 `O(N)`입니다.

### 3. 거리 이분 탐색

- 탐색 범위: `lo = 1`, `hi = (가장 오른쪽 집) - (가장 왼쪽 집)`
- `mid`에서 설치 가능 → `answer = mid`로 기록하고 더 큰 거리 시도 (`lo = mid + 1`)
- 불가능 → 거리를 줄임 (`hi = mid - 1`)

`mid = lo + (hi - lo) / 2`로 계산해 `int` 오버플로를 피했습니다.

## 예제 따라가기

입력 `1 2 8 4 9`, `C = 3` → 정렬 후 `1 2 4 8 9`, 범위 `[1, 8]`

| lo | hi | mid | 설치 위치 | 설치 수 | 결과 |
| --- | --- | --- | --- | --- | --- |
| 1 | 8 | 4 | 1, 8 | 2 | 불가능 → hi = 3 |
| 1 | 3 | 2 | 1, 4, 8 | 3 | 가능 → answer = 2, lo = 3 |
| 3 | 3 | 3 | 1, 4, 8 | 3 | 가능 → answer = 3, lo = 4 |

`lo > hi`가 되어 종료하고 답은 **3**입니다.

## 복잡도

- 시간: 정렬 `O(N log N)` + 이분 탐색 `O(N log(maxX))` (약 30회 × 200,000)
- 공간: `O(N)`

## 검증

- 예제 입력 → `3` 출력 확인
- 무작위 소형 입력 400개를 모든 조합을 확인하는 완전 탐색 결과와 비교해 모두 일치
- 최대 크기 입력(`N = 200,000`)에서 약 0.05초
