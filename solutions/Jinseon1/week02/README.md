# 2110. 공유기 설치

- 학습 주제: 정렬, 이분 탐색
- 사용 언어: C++

## 문제 분석
N개의 집 중 C개를 골라 공유기를 설치할 때, 공유기 사이의 최소 거리를 최대화하는 문제이다.
집이 최대 200,000개이므로 모든 설치 조합을 확인하는 방법은 비효율적이다.
따라서 최소 거리의 후보를 이분 탐색하고, 각 거리를 유지하며 C개 이상 설치할 수 있는지 확인했다.

## 풀이 과정
1. 집의 좌표를 오름차순으로 정렬한다.
2. 탐색 범위를 1부터 가장 오른쪽 집과 왼쪽 집 사이의 거리까지로 설정한다.
3. 중간값 mid를 공유기 사이의 최소 거리로 가정한다.
4. 첫 번째 집에 공유기를 설치하고, 마지막으로 설치한 집에서 mid 이상 떨어진 집을 만날 때마다 설치한다.
5. C개 이상 설치할 수 있으면 mid를 정답 후보로 저장하고 더 큰 거리를 탐색한다.
6. C개를 설치할 수 없으면 거리를 줄여 탐색한다.

조건을 만족하는 가장 앞쪽 집부터 설치하면 이후 공유기를 놓을 공간을 최대한 남길 수 있다.
또한 어떤 거리로 C개를 설치할 수 있다면 그보다 작은 거리에서도 가능하므로 이분 탐색을 적용할 수 있다.

## 복잡도
D를 가장 큰 좌표와 가장 작은 좌표의 차이라고 할 때,
정렬에 O(N log N), 이분 탐색에 O(N log D)가 필요하다.
전체 시간 복잡도는 O(N log N + N log D)이다.

## 실행 확인
예제 입력을 실행하여 출력이 3인 것을 확인했다.

## 배운 점
처음에는 공유기를 정확히 C개 설치할 수 있어야 조건을 만족한다고 생각하기 쉬웠다.
하지만 C개보다 많이 설치할 수 있다면 일부를 제거하여 C개만 남겨도 최소 거리 조건이 유지된다.
따라서 설치 개수를 확인할 때 cnt == C가 아니라 cnt >= C를 사용해야 하는 이유를 이해했다.
