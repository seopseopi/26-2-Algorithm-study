# BOJ 2110. 공유기 설치

- 문제 안내: [저장소의 2주차 공통 문서](../../../problems/week02/README.md)
- 백준의 이전 공식 주소: https://www.acmicpc.net/problem/2110 (서비스 종료로 현재 접속 불가)
- 난이도: solved.ac Gold IV
- 구현 언어: C++17

## 1. 처음 확인한 조건

집은 `2 ≤ N ≤ 200,000`개이고 공유기는 `2 ≤ C ≤ N`개입니다. 집 좌표는 `0`부터 `1,000,000,000`까지이며 서로 다른 위치에 있습니다. 공유기를 `C`개 설치했을 때 가장 가까운 두 공유기의 거리 중 최솟값을 최대화해야 합니다.

## 2. 단순한 풀이가 비효율적인 이유

공유기를 놓을 집의 조합을 모두 확인하면 경우의 수가 매우 커집니다. `N`이 최대 200,000이므로 조합을 직접 살펴보는 방식은 제한 시간 안에 끝나지 않습니다.

## 3. 선택한 알고리즘과 핵심 아이디어

집 좌표를 오름차순 정렬하고, 가능한 최소 거리 `d`를 이분 탐색합니다. 특정 `d`에 대해 가장 왼쪽 집에 먼저 설치한 뒤, 직전에 설치한 집과의 거리가 `d` 이상인 가장 빠른 집마다 설치합니다. 이 탐욕적 배치로 `C`개 이상 설치되면 `d`는 가능하므로 더 큰 거리를 확인하고, 아니면 더 작은 거리를 확인합니다.

## 4. 알고리즘이 올바른 이유

정렬된 집을 왼쪽부터 보며 가능한 가장 이른 위치에 설치하면, 이후 설치 가능한 집의 선택 폭을 줄이지 않습니다. 따라서 주어진 거리 `d`에서 이 방식으로 설치한 수는 가능한 설치 수의 최댓값입니다. `d`가 가능하면 그보다 작은 거리도 가능하고, 불가능하면 그보다 큰 거리도 불가능하므로 가능 여부가 한 방향으로 나뉩니다. 이 경계에서 가능한 최대 `d`를 이분 탐색으로 구합니다.

## 5. 시간·공간 복잡도

정렬은 `O(N log N)`입니다. 이분 탐색은 좌표 차이 범위에 대해 최대 약 30회 진행하고 매번 집을 한 번씩 확인하므로 `O(N log W)`이며, `W`는 가장 오른쪽과 왼쪽 집 좌표의 차이입니다. 전체 공간 복잡도는 좌표를 저장하는 `O(N)`입니다.

## 6. 구현 시 주의할 경계 조건

- 가능한 최소 거리의 하한은 1이고 상한은 양 끝 집 좌표의 차이입니다.
- `C = N`이면 모든 집에 설치해야 하므로 가장 작은 인접 좌표 차이가 답이 됩니다.
- 좌표와 차이의 최대값은 1,000,000,000으로 `int` 범위에 들어갑니다. 중간 거리 계산은 `left + (right - left) / 2`로 작성했습니다.
- 설치할 집이 `C`개보다 많아도 선택한 거리 `d`를 만족하는 `C`개를 고를 수 있으므로 `installed >= C`를 사용합니다.

## 7. 테스트 결과

아래 항목은 로컬에서 C++17로 컴파일해 실행 확인했습니다. 백준 제출은 하지 않았으므로 백준 정답 판정은 확인하지 않았습니다.

- 백준 예제: `5 3` 및 좌표 `1, 2, 8, 4, 9` → `3`
- 최소 집 수와 공유기 수: 좌표 `0, 1`, `C = 2` → `1`
- 전체 좌표 범위 경계: 좌표 `0, 1,000,000,000`, `C = 2` → `1,000,000,000`
- `C = N`, 균일 간격: 좌표 `0, 10, 20, 30`, `C = 4` → `10`
- `C = N`, 불균일 간격: 좌표 `0, 2, 9, 15`, `C = 4` → `2`
- 중복 좌표: 문제 입력은 서로 다른 집 좌표를 보장하므로 유효 입력 테스트에 포함하지 않았습니다.
- 소규모 무작위 테스트: 서로 다른 좌표 집합으로 500개 입력을 만들고 모든 공유기 조합을 열거한 기준 풀이와 비교했습니다.
- 큰 입력: 200,000개 좌표 `0`부터 `199,999`까지, `C = 100,000`으로 실행해 결과 `2`를 확인했습니다. 로컬 실행 시간은 약 0.235초였습니다.
- 컴파일: `g++ -std=c++17 -O2 -Wall -Wextra -pedantic`으로 경고 없이 완료했습니다.

## 8. 학습 포인트

최댓값을 직접 구성하는 대신, 후보 거리의 가능 여부를 판단하는 결정 문제로 바꾸면 이분 탐색을 적용할 수 있습니다. 정렬된 자료에서 가장 이른 가능한 위치를 고르는 탐욕적 검사가 이분 탐색의 판정 과정으로 쓰입니다.
