
# Week 02 - 공유기 설치

## 1. 문제 정보
- 문제 번호: BOJ 2110
- 문제 이름: 공유기 설치
- 난이도: Gold IV
- 알고리즘: 정렬, 이분 탐색

## 2. 문제 분석
N개의 집 중 C개의 집에 공유기를 설치해야 한다.
가장 인접한 두 공유기 사이의 거리를
최대한 크게 만드는 것이 목표이다.

## 3. 풀이 방법
1. 집의 좌표를 오름차순으로 정렬한다.
2. 공유기 사이의 최소 거리를 이분 탐색한다.
3. mid를 최소 거리로 가정하고 공유기를 설치한다.
4. C개 이상 설치할 수 있다면 거리를 늘린다.
5. C개 미만 설치할 수 있다면 거리를 줄인다.
6. 설치 가능한 최대 최소 거리를 출력한다.

## 4. 시간 복잡도
- 정렬: O(N log N)
- 이분 탐색: O(N log D)
- 전체: O(N log N + N log D)

D는 가장 오른쪽 집과 가장 왼쪽 집의
좌표 차이이다.

## 5. 배운 점
이분 탐색은 특정 값을 찾을 때뿐 아니라
조건을 만족하는 최댓값을 찾을 때도
사용할 수 있다는 것을 알게 되었다.

이 문제에서는 집의 위치가 아니라
공유기 사이의 최소 거리를 탐색한다는
점이 핵심이었다.
